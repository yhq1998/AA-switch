AA Switch 3.0.3 同步更新 macOS 与 Windows 的菜单图标和主窗口样式。

- 为刷新状态、检查更新、导出诊断信息和开机自启增加彩色图标；macOS 的 Claude 环境检测使用橙色盾牌图标，开机自启的勾选状态保留。
- 主窗口统一正文与按钮字号、控件高度及间距。模式开关、“更多”和操作按钮等宽对齐，操作区竖排，避免按钮超出窗口边界。
- 底部“关闭窗口”和“退出”两个按钮等宽排列，说明文字与版本号使用辅助字号。
- 去掉“Claude 环境检测”和“导出诊断信息”末尾的省略号，主窗口“更多”的标题也简化。

macOS 本机试用已确认。两端共享界面同步调整；Claude 环境检测仍仅在 macOS 提供。macOS 安装包使用 Developer ID 签名及 Apple 公证，Windows 为自带运行时的 64 位单文件程序。官网与 GitHub Release 使用同批构建产物，源码提交及 SHA256 见附带清单。
