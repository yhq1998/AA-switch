AA Switch 3.0.0 整合 macOS 环境检测与菜单体验更新。

- 主窗口底部左侧增加“关闭窗口”，收起弹窗后继续在菜单栏运行；“退出”位于同一行右侧，用于退出整个应用。菜单栏中的退出入口保持原样。
- “Claude 环境检测…”常驻主菜单，账号和 API 模式都能使用；原样复用 Claude Switcher 的 14 项检测和 STUN 探针，支持设置、重新检测与导出。
- Codex 与 Claude 的“更多”操作使用一致的固定功能图标，并适配 macOS 27 的图标显示。
- API 地址与切换说明集中到各自的“更多”详情区，精简主菜单。

环境检测沿用上游 Claude 账号环境标准，不检测自定义 API 网关，不能保证账号可用或防止 IP 泄漏；原版 STUN 探针需要 Python 3。

本次先安装本机试用，不发布线上。Windows 本次未增加上述 macOS 界面和环境检测功能。
