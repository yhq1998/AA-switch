AA Switch 3.0.5 改进 macOS 与 Windows 的本地 Cowork / Tasks 会话同步，兼容 Claude Desktop 的更多存储格式。

- 同时扫描外层和 `agent/` 子目录，支持账号、组织和正文目录的 8 位短名，以及 ID 中带额外下划线的合法会话。
- 修补“列表项已复制但正文缺失”的旧副本，复制正文时一起改写路径，并保留签名日志原文。
- 同步账本按源/目标目录分别保存，切换存储目录后不再混用旧目录的删除判断；切回原目录仍保留其删除与冲突状态。
- 源正文缺失或复制失败时明确报告，保留原会话并允许下次重试。
- 明确区分本地 Cowork / Tasks 与普通 Chat：本次不迁移普通 Chat 云端历史。Tasks 的界面名称变化本身不会影响同步。

已有用户升级后，重新应用 API 配置或切换账号/API 即会执行同步。旧账本曾把缺失列表项误记为删除的情况仍需核对具体会话后恢复；不会清空全部账本或自动合并两边都续聊过的冲突。

两端共享行为同步更新。macOS 的 Claude 切换脚本为 1.4.6；macOS 安装包使用 Developer ID 签名和 Apple 公证，Windows 为自带运行时的 64 位单文件程序。官网与 GitHub Release 使用同批构建产物，附带源码提交及 SHA256 清单。
