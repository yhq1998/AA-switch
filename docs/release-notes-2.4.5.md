AA Switch 2.4.5 为 macOS 的 Claude 账号模式增加“账号环境检测…”入口。

- 原样复用 Claude Switcher 固定提交的全部 14 项检测函数与 Python STUN 探针，保留 MIT 许可和来源校验。
- 首次确认代理客户端、目标国家、时区、地区及 Clash Verge 代理组；支持重新检测和手动导出结果。
- 仅在 Claude Code 处于账号模式、桌面应用处于账号模式或未安装时显示入口。检测不修改系统或代理设置、不安装守护进程、不操作登录快照。
- 原版 STUN 探针需要已安装 Python 3；缺少依赖时明确提示。检测结果、出口 IP 历史保存在 AA Switch 独立的本机目录。
- 检测标准与原项目一致，包含 fake-IP/TUN、IPv6、客户端语言及既有保镖检查，不能保证账号可用或防止 IP 泄漏。

内置 codex-mode 2.2.6、claude-mode 1.4.3 不变。Windows 本次未增加环境检测功能。

本次先在本机试用，试用确认后再发布线上版本。
