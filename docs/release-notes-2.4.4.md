AA Switch 2.4.4 统一更新 macOS 和 Windows 发布包，解决同标 2.4.2 的安装包内容不同、检查更新却无法取得修复的问题。

- 两个平台的 Claude 桌面网关配置都包含外网域名放行和网关测试客户端标识修复。升级后，在 Claude Code 的“更多”中选择“重新应用 API 配置并重启 Claude 桌面应用”，更新已有网关配置。
- macOS 切换 Codex 时自动关闭当前用户的桌面、终端和 IDE 后台进程，解决任务已结束仍提示会话运行的问题。正在执行的任务会中断；桌面应用会重新打开，终端和 IDE 会话需自行重开。无法关闭时停止修改配置，并列出剩余 PID。
- 修复 macOS 菜单标题图标显示；内置脚本即使版本相同但内容不同，也会备份并修复安装。
- 发布包加入源码提交和 SHA256 清单；阻止旧构建、同版本不同内容和降级发布。Windows 测试失败会停止打包，官网在安装包上传完成后才更新版本索引。

macOS 内置 codex-mode 2.2.6、claude-mode 1.4.3。Mac 包使用 Developer ID 签名与 Apple 公证；Windows 为自带运行时的 x64 单文件程序。

验证：macOS 隔离冒烟测试、Codex 进程回归测试、发布一致性回归测试、Windows 单元测试与跨平台构建、官网构建；发布后重新下载官网和 GitHub 的文件核对哈希及包内版本。实际验证结果见发布任务。
